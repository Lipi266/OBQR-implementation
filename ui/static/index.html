Phase 1 — Clustering by direction (Algorithm 1)

Every car sends a beacon with its id, position, speed and direction. For each neighbour j:

εij = (Vi·Vj) / (‖Vi‖‖Vj‖)  (Eq. 6) — cosine similarity
k̂ij = 1 − εij  (Eq. 7)    ρ̂i = (1/N) Σ k̂ij  (Eq. 8)

Neighbours with k̂ below the threshold ρ̂ are "similar". The car with the lowest cosine distance and the most neighbours becomes the cluster head; the others join it.

Same direction: ε = 1 · crossing street: ε = 0 · oncoming lane: ε = −1.

Phase 2 — QoS routing (Algorithm 2)

Each link gets three numbers:

  • Link life (Eq. 12): how long the two cars stay in radio range, from their positions and velocities
  • Cost (Eq. 13–14): from a Gaussian link-quality model
  • Delay: time to send a packet over the link
W = α·(life) + β·(cost) + γ·(delay), each scaled to 0–1, α + β + γ = 1  (Eq. 15–16)

Longer-lasting, cheaper and faster links get a lower weight. The source finds the 3 paths with the lowest total W: it uses the best and keeps the other two as backups. We use α = 0.4, β = 0.3, γ = 0.3.
